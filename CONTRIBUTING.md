# Contributing to OntoUML DirectKG

OntoUML DirectKG is an open-source Python project for transforming OntoUML models into domain-oriented RDF/OWL ontologies. Everyone is welcome to use and explore the project, report bugs and unexpected behavior, suggest improvements and features, improve documentation, and contribute code or other enhancements.

## Issues

Use [GitHub Issues](https://github.com/pedropaulofb/ontouml-directkg/issues) to report problems, ask project-related questions, discuss ideas, or propose improvements.

Check for a relevant existing issue first. For bug reports, include steps to reproduce the problem, expected and actual behavior, and relevant version details. A small example is helpful when available.

## Pull requests

[Pull requests](https://github.com/pedropaulofb/ontouml-directkg/pulls) are welcome for corrections, documentation improvements, bug fixes, and new functionality.

- Keep changes focused and explain what they change and why. Link a related issue if one exists.
- Follow the existing code and documentation style. Start with the [README](README.md) and consult the [development guide](documentation/site/development/contributing.md) for relevant conventions and documentation checks.
- Run checks relevant to your change and describe the results or any limitations. See the [test instructions](tests/README.md) for setup and test scope.
