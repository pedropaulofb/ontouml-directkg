dkgm:
Scope Note

References to collectives, quantities and functional complexes in the definitions describe intended use; they are not formal RDF domain or range constraints.

Source-specific properties may be asymmetric subproperties of DKGM properties. This does not make the generic DKGM properties asymmetric.

Description

  • Reusable generic OWL properties for DirectKG mappings of four OntoUML mereological relation stereotypes.

  • Source-specific relations generated by DirectKG can be subproperties of these generic properties. This vocabulary is not the OntoUML metamodel vocabulary.

Object Property Definitions

component of op

IRI https://w3id.org/directkg/vocab/dkgm#componentOf
Is Defined By DirectKG Mereology Vocabulary
Definition

Relates a functional complex to a functional complex of which it is a component.

Description

Generic DirectKG property corresponding to the OntoUML «componentOf» stereotype. Transitivity is not asserted because it depends on context.
Scope Note

The absence of a transitivity axiom leaves transitivity unspecified; it does not assert universal intransitivity.
See Also https://ontouml.readthedocs.io/en/latest/relationships/aggregations/componentOf/index.html

member of op

IRI https://w3id.org/directkg/vocab/dkgm#memberOf
Is Defined By DirectKG Mereology Vocabulary
Definition

Relates a member to a collective of which it is a member.

Description

Generic DirectKG property corresponding to the OntoUML «memberOf» stereotype.
Scope Note

A conclusion inferred by a generic DKGM property chain uses the generic property; it does not identify a particular source-specific relationship.
Example

Declaring ex:teamMembership rdfs:subPropertyOf dkgm:memberOf makes each ex:teamMembership statement a generic dkgm:memberOf statement. Generic membership alone does not entail ex:teamMembership.

If ex:alice dkgm:memberOf ex:team and ex:team dkgm:subCollectionOf ex:organisation, the membership chain entails ex:alice dkgm:memberOf ex:organisation.
See Also https://ontouml.readthedocs.io/en/latest/relationships/aggregations/memberOf/index.html
